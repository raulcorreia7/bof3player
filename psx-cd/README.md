# psx-cd

Read and write PlayStation CD-ROM images: ISO 9660 file tables, Mode 2 XA sectors (2336 bytes), CUE/BIN sheets, CD-DA track extraction, checksum manifests, and a patch writer that re-seals replaced files.

```sh
# from the repository root
cargo test -p psx-cd --all-features
```

Guide: [psx-cd](../docs/crates.md#psx-cd).

> A fan project, not affiliated with Capcom. *Breath of Fire* is Capcom's trademark. No game data is included; bring your own disc.
